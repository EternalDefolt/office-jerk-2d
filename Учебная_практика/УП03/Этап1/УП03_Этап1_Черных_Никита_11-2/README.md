# Office Jerk 2D

Авторская десктопная инди-игра в жанре *stress-reliever / narrative-action* на движке
**Godot 4.6** (GDScript) под Windows 10/11. По мотивам мобильной *Office Jerk*
(Fluik, 2011), переосмысленная как локальный безрекламный 2D-проект с физическим
манекеном и поведенческой AI-моделью.

## Что делает программа

Игрок управляет персонажем в офисной комнате и взаимодействует с манекеном-целью:
четырёх-направленное движение (WASD) с инерцией, прицеливание мышью, удары ЛКМ с
чередованием рук, блок ПКМ и многофазный финишный приём (захват + бросок). На стороне
манекена работают точечный рэгдолл (6 узлов с дистанционными констрейнтами) и
поведенческая система реакций **BodyAI** (8 намерений + случайные микротвитчи).

## Для кого

Одиночный игрок 20–40 лет, ценящий короткую сессию (1–5 минут), выразительный
визуальный стиль (пиксель без сглаживания, «раздельные» части тела как в Madness Combat)
и физически достоверную реакцию цели. Монетизации и сети нет.

## Стек

| Слой | Технология |
|------|------------|
| Движок | Godot Engine 4.6.x (renderer: `gl_compatibility`) |
| Язык | GDScript |
| Тесты | gdUnit4 (addons/gdUnit4) |
| Dev-тулинг | Python 3 + google-genai / Playwright (генерация спрайтов, необязательно) |
| Платформа | Windows 10/11, экспорт desktop |

## Как запустить (коротко)

```bash
# 1. Клонировать
git clone https://github.com/EternalDefolt/office-jerk-2d
# 2. Открыть в Godot 4.6 (импорт ассетов произойдёт автоматически)
Godot_v4.6.x_win64.exe --path . --editor
# 3. Запустить главную сцену
Godot_v4.6.x_win64.exe --path . res://scenes/main.tscn
```

Подробная пошаговая инструкция — в `03_Инструкция_запуска.md`.
