# 03. Инструкция запуска проекта «Office Jerk 2D»

Инструкция рассчитана на запуск проекта **на другом компьютере с нуля**.
Игра — десктопный Godot-проект, поэтому ни базы данных, ни сервера, ни файла `.env`
для запуска **не требуется**.

## Требования

| Компонент | Версия | Как проверить |
|-----------|--------|----------------|
| Godot Engine | 4.6.x (stable) | `Godot_v4.6.x_win64.exe --version` |
| ОС | Windows 10/11 x64 | `winver` |
| Видео | поддержка OpenGL 3.3 (renderer gl_compatibility) | любая интегрированная/дискретная GPU |
| Git | любая | `git --version` |
| Python 3 *(необязательно)* | 3.10+ | только для dev-скриптов генерации спрайтов |

> Godot 4.6 поставляется одним исполняемым файлом (~100 МБ), установка не требуется.
> Скачать: https://godotengine.org/download

## Шаги запуска

### Шаг 1. Скачать проект
```bash
git clone https://github.com/EternalDefolt/office-jerk-2d
cd office-jerk-2d
```
Ожидаемый результат: появилась папка проекта с `project.godot`.
Скриншот: `screenshots/01_repo_structure.png`

### Шаг 2. Импортировать ассеты (аналог «установки зависимостей»)
В Godot-проекте роль зависимостей играет сам движок + импорт ресурсов.
Первый запуск импортирует спрайты и плагин gdUnit4 автоматически:
```bash
Godot_v4.6.x_win64.exe --headless --path . --import
```
Ожидаемый результат: `[ DONE ] first_scan_filesystem`, ошибок импорта нет.
Скриншот: `screenshots/02_install_dependencies.png`

### Шаг 3. (Опционально) Настроить .env для dev-скриптов
Нужно **только** если будете генерировать новые спрайты через Gemini.
Для запуска игры пропустите этот шаг.
```bash
copy .env.example .env      # Windows
# затем впишите свой GEMINI_API_KEY
```
Скриншот: `screenshots/03_env_example.png`

### Шаг 4. Запустить игру
```bash
Godot_v4.6.x_win64.exe --path . res://scenes/main.tscn
```
Или: открыть проект в редакторе (`--editor`) и нажать **F5**.
Ожидаемый результат: открывается окно 1280×720, в консоли —
`[DEV_EYE] Auto OFF. F9 = manual screenshot`. Лог: `logs/app_start_log.txt`.
Скриншот: `screenshots/04_success_run.png`

### Шаг 5. Проверить работу
В окне игры: WASD — движение, мышь — прицел, ЛКМ — удар, ПКМ — блок, X — финишер.
Скриншот: `screenshots/05_app_working.png`

## Возможные проблемы

| Симптом | Причина | Решение |
|---------|---------|---------|
| Чёрное окно / нет спрайтов | ассеты не импортированы | выполнить Шаг 2 (`--import`) |
| «failed to load» по плагину | gdUnit4 не импортирован | открыть проект в редакторе один раз |
| Скрипты `asset_gen.py` падают | нет `GEMINI_API_KEY` | создать `.env` (Шаг 3) — для игры не нужно |
| На GitHub нет PlayerInput/Combat/Animator и tests/ | локальные изменения не запушены | `git add -A && git commit && git push` |
