# Учебная практика — «Office Jerk 2D»

Эта папка хранит материалы учебной практики по проекту. Каждый этап — отдельная
подпапка, чтобы сдачи не смешивались и историю было видно прямо в репозитории.

## Структура

```
Учебная_практика/
├── УП03/
│   ├── Этап1/          ← входной аудит проекта и подготовка к запуску
│   │   ├── УП03_Этап1_Затонский_Егор_9-3/
│   │   └── УП03_Этап1_Черных_Никита_11-2/
│   ├── Этап2/          ← (следующий этап — добавится сюда)
│   └── ...
└── УП02/               ← (при желании можно перенести материалы УП.02 из docs/)
```

## Правило загрузки этапов

1. Новый этап → новая папка `УП03/ЭтапN/`.
2. Внутри — папка по шаблону `УП03_ЭтапN_Фамилия_Имя_Группа/` на каждого студента.
3. Состав папки этапа: README, отчёт `.docx`, таблицы `.xlsx`, `.env.example`,
   инструкция запуска, `screenshots/`, `logs/`.
